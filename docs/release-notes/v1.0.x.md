# Release Notes — Initial Public Release

## Highlights

- **`medios v0.1.14`:** `medios-controller`, `medios-node`, `medios-execute`, `medios-local`, and node helper binaries.
- **`medios-sdk-go v0.15.0`:** Official reference Go SDK at [`medios-lab/medios-sdk-go`](https://github.com/medios-lab/medios-sdk-go).
- **`ray-medios v0.1.0` (preview):** KubeRay-compatible framework running stock Ray `2.60.0` `kuberay-autoscaler` on Medios ([Ray on Medios](/frameworks/ray-on-medios)).
- **Public docs & OpenAPI 3.1.0:** Dedicated documentation site with `/llms.txt`, scoped agent bundles, raw `/md/` mirrors, and full ProtoJSON OpenAPI 3.1.0 specs.

## Core (`medios v0.1.14`)

- Single-containerizer-per-cluster execution (`medios` OCI containerizer or `docker_shell` CLI containerizer).
- Optional etcd v3 HTTP/JSON controller leader election and `leveldb` controller registry persistence.
- Operator-declared GPU isolation (`com_medioslab_medios_gpu`), shared dataset stores (`--stores`), atomic multi-node gang admission (`REQUEST`), two-tier principal attribution (`TaskInfo.principal`), mutual TLS (`MEDIOS_ENABLE_SSL`), structured progress with stall detection, sidecar task observers, and post-exit finish hooks.
- Embedded runtime `/openapi.json` and `/.well-known/openapi.json` discovery endpoints (full ProtoJSON schema embedding lands in a follow-up `medios` release).

## Go SDK (`medios-sdk-go v0.15.0`)

- Full HTTP v1 scheduler client, RecordIO codec, unknown-field-preserving resource carving (`CarveScalar`/`CarveScalars`), `ClusterView`, `WithStore`, `WithObserver`, `ProgressPolicyForProfile`, `sandbox.Resolver.CaptureTail`, and pure-Go SQLite `store`.

## Known

- See [Known Issues](/known-issues) for macOS hostname resolution, Docker-on-Mac cgroups, and containerizer constraints.
